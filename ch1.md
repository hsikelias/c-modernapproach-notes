## Origins

By prodct of UNIX operating system, developed at bell laboratories by **Ken Thompson**, **Dennis Ritchie** and others.

C offered portability once the compilers were made, it ran on variety of machines and not just unix.

Development for the C began in 1983 under the auspices of the **American National Standards Institute(ANSI).**
Got Approved in 1990 and this version is referred to as C89 or C90, the old version is usually called K&R C.

## C influences on languages
__C++__: Includes all features of C,adds classes and other features to support OO 
__Java__: C++ influences
__C#__: Derived from C++ and Java
__Perl__: Scripting language that adopted many features of C

## Strengths and Weaknesses of C

- C is low level, suitable language for systems programming. You get access to machine level concpets like bytes and
addresses, operations close to computer built in instructions.
- C is small, limited set of features.
- Efficiency is a huge thing in C, since it was traditionally made to use in programs that used assembly, it was important
for C programs to run quickly in limited amount of memory.
- Portability
- Flexibility, C can be used in other fields than just for systems programming. It has very few restrictions on its features which
would be illegal in other languages.


- C is a **error-prone language**, not all mistakes are detected by a C compiler. Like assembly, most errors are not detected until
the program is run.
