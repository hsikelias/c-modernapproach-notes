# C INTRODUCTION


C is product of the UNIX operating system, like other operating systems at that time, UNIX was written in assembly as well.

C is built upon the B language, which was made for the PDP-11. The language was stable by 1973 that UNIX was rewritten in C.


The original version of C, was called K&R C, a new standard was published, ISO/IEC 9899:1999, in 1999. The language described in this standard is known as *C99*. 

## Influences of C

- C++: Pretty much has everything that C does, but adds classes and supports OOP.
- Java: is based on C++ so it has features of C
- C#: Derives things from C++ and Java
- Perl: A scripting language that has grown and adopted many features of C.

## Strengths and Weaknesses of C

C is not very abstract like other language, C gives you direct access to machine-level concepts, it provides instructions to correspond closely to a computer's built-in instructions. Relative to many other languages, C is relatively short. To keep the number of features small, Crelies heavily on library of standard functions.  


**GOOD** 
- Efficiency, C was made arround the time when programmers where making softwares with assembly, so C was made to be fast and be used in limited amounts of memory.
- Portability
- Power
- Flexibility, though C was designed for things like systems programming, it has no restrictions on where you want to use it now,except webdev maybe lol. C also imposes very few restictions to the features you want to use.

**BAD**
- Error-Prone, programming mistakes can be caught in many other languages but, C compiler barely helps you, you won't detect most of the errors until the program is run.
- Sometimes, C can be difficult to understand.
- C programs can be difficult to modify, since it doesn't have things like classes and packages, which divide a large program into more small pieces.
